# 创业领导力 · 核心自检（38 条）

浙大管院 MBA《创业领导力》(C11) 课程配套的**核心条目自检工具**。单文件、零依赖、纯前端，所有数据存在你自己的浏览器里。

## 怎么用

打开页面 → 逐条自评（0—5 分）→ 提交 → 看报告。

- **问号按钮**：不确定这条在说什么，点标题旁 `?`，弹出该条的知识点内核、三条判断标准、"用坏的样子"、下一步动作、课件出处。
- **中途保存**：每答一题自动写入浏览器本地存储（localStorage）。关掉页面再来，封面会出现「继续上次」。
- **评分**：38 条 × 0—5 分，满分 190。按总分折算五档：**S ≥ 4.5 / A ≥ 3.8 / B ≥ 3.0 / C ≥ 2.2 / D < 2.2**。
- **报告**：总分、档位、九域雷达式条形、"先补三件"（点击可直接跳回原题）、一句话结论、历史趋势折线。
- **JSON 导出**：全量数据（每轮逐题答案、备注、跳过项、九域得分、强弱项、评级、用时）。用于长期跟踪与跨设备迁移。导入后自动回到报告页。
- **海报导出**：1080×1380 的 PNG，含分数、档位、九域条形、三件待补。用于分享。

## 数据说明

数据只存在浏览器 `localStorage`（键 `c11core.runs.v1`），不上传任何服务器。换浏览器、换域名、清缓存都会丢——**长期跟踪请定期导出 JSON**。

从本地文件迁移到本页：在旧页面导出 JSON，在本页「导入」即可，历史记录会合并。
